  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "kernellake.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}

Then connect with any Arrow Flight SQL client, e.g. the ADBC Python driver
(the same one used to verify kernellake-server itself -- see
docs/ARCHITECTURE.md's "Arrow Flight SQL server" section):

  import adbc_driver_flightsql.dbapi as flight_sql
  conn = flight_sql.connect("grpc://localhost:{{ .Values.service.port }}")
  cur = conn.cursor()
  cur.execute("SELECT region, SUM(amount) AS total FROM read_parquet('/data/*.parquet') GROUP BY region")
  print(cur.fetchall())
